### About Me

I am a professional **Web Developer** and **Cyber Security Researcher** based in Peshawar, Pakistan. I engineer high-performance decentralized applications, secure Web3 infrastructure, and resilient digital architectures.

My work focuses on writing clean, scalable code across TypeScript, Next.js, and smart contract ecosystems, with a dedicated emphasis on cryptographic verification, Ed25519 identity systems, and trustless deal-making protocols.

- **Focus**: Distributed systems, cryptographic settlement engines, and autonomous agent infrastructure.
- **Experience**: 4+ years of development, with 18+ shipped projects and comprehensive protocol audits.
- **Live Work**: Explore live demos and client work on [asad-lee-portfolio.vercel.app](https://asad-lee-portfolio.vercel.app/).
